

项目名称：AI考公陪练 —— 大白话讲题 + 举一反三

项目目标

开发一个微信小程序（先做Web版），帮助公务员考试考生彻底搞懂每一道错题。核心价值不是给答案，而是用大白话、分步骤、可追问的方式讲解，直到用户真正理解，然后自动生成2-3道同类考点/陷阱的练习题巩固。

用户场景与功能需求（MVP）

前端（微信小程序优先，也可Web）

1. 输入方式：
   · 文本粘贴输入
   · 拍照上传并OCR识别文字（可选，MVP可先做纯文本）
2. 处理与反馈：
   · 用户提交题目后，显示加载动画。
   · 返回结果分为三块：
     · 大白话题意重述：一句话说清楚题目在问什么。
     · 分步解析：拆成2-4步，每步解释“为什么这么想”，避免术语。
     · 互动按钮：“懂了，继续” 和 “没懂，再讲一遍”。
       · 点“没懂”时，AI换一种角度重新讲解（调用同一API但增加参数 rephrase=true）。
       · 点“懂了”后，显示“举一反三”板块，列出2-3道相似题（只给题目+正确答案，不解析，或可点击请求解析）。
3. 辅助功能：
   · 错题本（本地存储或云数据库），用户可收藏题目。
   · 底部导航：首页、我的错题本。
4. 风格要求：
   · 初期简洁、干净、易用。后期可升级为深色毛玻璃等“电影级质感”。

后端API

· 接收用户输入的题目文本（以及可选的重讲标志）。
· 调用大模型API（使用 DeepSeek V4-Pro，因为性价比高）。
· 返回结构化JSON，例如：

```json
{
  "simple_explanation": "大白话...",
  "step_by_step": ["步骤1", "步骤2", ...],
  "similar_questions": [
    {"question": "...", "answer": "..."}
  ]
}
```

· 需要实现缓存机制：对相同题目文本，直接返回缓存结果，降低成本（高频考题缓存命中率可做到60%+）。
· 注意：Claude Code或类似工具调用时的固定Token消耗（约27k tokens/次）要通过合理设计减少影响。

Prompt 模板（给AI模型用）

```
你是公务员考试辅导专家。用户给你一道行测或申论题。请按以下步骤输出：

1. 大白话题意：用最通俗的语言，一句话说清楚题目在问什么。
2. 分步解析：把解题思路拆成2-4步，每一步写清楚推理过程，避免专业术语。
3. 生成2道相似题目（仅题干和正确答案，不要解析），这些题目要换数字、换场景但核心逻辑相同。

输出严格JSON格式，字段名为：simple_explanation, step_by_step, similar_questions（每个元素含question和answer）。
```

技术栈建议（低成本 + 快速部署）

· 前端：微信小程序原生框架（或uni-app） + Tailwind CSS。
· 后端：微信云开发（云函数） 或 独立FastAPI（部署在 Railway/Vercel）。
· 数据库：云开发数据库 或 Supabase（存储用户错题本）。
· 大模型API：DeepSeek V4-Pro（输入缓存命中0.025元/百万tokens，未命中3元/百万tokens，输出6元/百万tokens）。
· OCR：可选，初期不强制，后续用微信OCR或腾讯云。

成本控制与优化

· 缓存策略：Redis或内存缓存相同题目（MD5），大幅减少重复调用。
· 最大Token限制：每次API调用输出不超过1000 tokens。
· 重讲机制：二次重讲时，只需要重新生成解析部分，相似题可复用第一次的结果。
· 预算估算：假设每天100个用户，每人问5个不同题目，且缓存命中率70%，日均成本约0.3-0.5元人民币。
